## Code change made during QA

`frontend/lib/src/data/paper_repository.dart` now applies a 15-second timeout
to `FilePicker.pickFiles`. If the native picker does not answer, the existing
error path runs and `finally` resets the upload state, so the screen cannot be
permanently stuck at 0%.

## Notes and remaining beta limitations

- Research-gap candidates require accepted/reviewed evidence. The UI leaves
  unsupported or unverified results reviewable and does not promote them to a
  final gap automatically.
- The local beta server and its database/worker must remain running for public
  users to connect. The Account privacy dialog exposes that dependency to users.
- The four export actions require at least one paper with status `Siap`.
